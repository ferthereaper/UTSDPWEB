3. Cara menjalankan

  • Jobsheet 01–05 dapat dibuka langsung (klik dua kali index.html).
  • Jobsheet 06 harus lewat server lokal. fetch() ke file JSON diblokir browser pada alamat file://. Gunakan ekstensi Live Server di VS Code (di folder ini sudah diatur port 5501 pada .vscode/settings.json) atau jalankan python -m http.server di folder Jobsheet-06.
  • Untuk menguji penanganan error, ubah sementara nama file di fetch menjadi yang tidak ada (mis. bukux.json); pesan “Gagal memuat data buku …” akan tampil di tabel.

5. Konsep kunci yang dipakai

HTML semantik

Memakai tag yang menyatakan makna (header, nav, main, section, article, footer) alih-alih div di mana-mana. Manfaatnya: mudah dibaca, ramah SEO, dan dipahami pembaca layar.

Path relatif

Alamat file relatif terhadap file yang sedang dibuka. ../ = naik satu folder. Dari buku/list.html, stylesheet berada di ../assets/css/style.css.

Class vs id

class boleh dipakai banyak elemen (.button-hapus), id harus unik di satu halaman (#search-input). Di CSS: titik untuk class, tanda pagar untuk id.

CSS Grid

Tata letak dua dimensi. Di proyek ini body dibagi menjadi sidebar 260px + konten (grid-template-columns: 260px minmax(0, 1fr)); kartu ringkasan dibagi 4 kolom.

Flexbox

Tata letak satu dimensi untuk menyusun anak secara baris/kolom. Dipakai pada isi header dan daftar menu.

position: sticky

Sidebar tetap menempel di sisi layar ketika konten digulir; syaratnya ada top dan align-self: start pada grid.

Media query

@media (max-width: 768px) membuat aturan CSS hanya berlaku pada layar tertentu. Breakpoint proyek: 1024px, 768px, 500px.

DOM

Representasi halaman HTML sebagai pohon objek yang bisa diubah JavaScript (querySelector, createElement, remove).

Event listener

Fungsi yang dipasang untuk bereaksi pada kejadian (click, keyup, submit, DOMContentLoaded).

Event delegation

Memasang satu listener di elemen induk (document) untuk menangani anak yang dibuat dinamis. Memanfaatkan bubbling: event naik dari elemen yang diklik ke leluhurnya.

fetch & JSON

fetch(url) meminta data lewat HTTP; JSON adalah format teks data (array/objek) yang diubah ke objek JS dengan response.json().

Promise, async, await

async function mengembalikan Promise; await menjeda fungsi sampai Promise selesai tanpa membekukan halaman.

try / catch / finally

Penanganan error: try mencoba, catch menangani kegagalan, finally selalu jalan (cocok untuk menyembunyikan loading).

Template literal

String berbackticks yang boleh multibaris dan menyisipkan nilai dengan ${...}.

XSS & escape

Menyisipkan teks mentah ke innerHTML berbahaya bila teks berisi tag. escapeHtml() mengubah karakter khusus menjadi teks aman.

dataset (data-*)

Atribut kustom data-xxx di HTML dibaca JS lewat elemen.dataset.xxx. Dipakai untuk data-kolom-nama dan data-label.

6. Alur kerja program (Jobsheet 06)

Urutan kejadian saat buku/list.html dibuka (halaman anggota identik dengan anggota.js):

  1. Browser membaca buku/list.html, memuat style.css, lalu mengeksekusi app.js dan buku.js secara berurutan. Pada tahap ini hanya definisi fungsi dan pendaftaran listener yang terjadi.
  2. Saat HTML selesai dibaca, event DOMContentLoaded memicu listener dalam urutan pendaftarannya: (1) handler app.js menjalankan initNavToggle, initHapusConfirm, initTableFilter, initValidasiForm, updateCounter (teks sementara: “Menampilkan 0 dari 0 buku”); (2) handler buku.js menjalankan muatBuku().
  3. muatBuku() menampilkan indikator loading, menunggu 600ms (delay), lalu fetch("../data/buku.json"). Respons dicek (response.ok), diubah menjadi array (response.json()), dan renderBuku() mengisi <tbody>.
  4. Jika terjadi kesalahan (file tidak ada, JSON rusak, dibuka lewat file://), catch menampilkan pesan “Gagal memuat data buku: …” di dalam tabel.
  5. finally menyembunyikan indikator loading dan memanggil updateCounter() → “Menampilkan 10 dari 10 buku”.
  6. Pengguna mengetik di kotak pencarian → event keyup → baris yang judulnya tidak mengandung kata kunci diberi display: none → updateCounter() memperbarui angka.
  7. Pengguna menekan Hapus → listener di document menangkap klik (delegation) → confirm() → bila OK, baris dihapus dari DOM → updateCounter().
